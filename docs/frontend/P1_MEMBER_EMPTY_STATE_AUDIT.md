## 5. 会员页「您有 0 张优惠券可用」

**代码：** `MemberCard.vue` L51–L54  

有 `bannerInfo` 就渲染：

- 标题：`您有{{ bannerInfo.couponCount }}张优惠券可用` → 零张时变成 **「您有0张优惠券可用」**
- 按钮：去点餐（`$emit('go-order')`）—— **下一步已经有**

| 问 | 答 |
|---|---|
| 字面？ | 0 张时成立 |
| 用户理解？ | **差。** 像空头支票或坏数据，不像邀请去点餐攒券 |
| 缺入口？ | **不缺。** 同卡已有「去点餐」；资产格也能进券列表 |

这不是空状态组件问题，是 **有数据时的主标题写了零**。

**建议（不实施，且不在「我的」加入口）：**

- `couponCount > 0`：保持「您有 N 张优惠券可用」+ 去点餐  
- `couponCount === 0`：标题改成「去点餐，结算自动用优惠」或隐藏整张主卡，只留积分/券数字格  

**产品决策：** 改标题 vs 隐藏整卡。倾向改标题、留按钮（少改布局）。  
**禁止：** 为此在 `mine.vue` 加优惠券行（P1-3，本阶段明确不做）。
