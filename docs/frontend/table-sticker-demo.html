什么时候选：店里桌数多、服务员要靠贴纸快速对桌时。超大桌号一眼可读，隔一张桌子也看得清。

两版都要做到的（和排版无关）：
  • 确认是正式版小程序码，不是体验版——体验版只有白名单手机能扫，试运营必翻车。
  • 印之前用两台手机各扫一次，核对进入的是本店、桌号对得上，再批量印。
  • 试运营用方形贴纸即可；正式版建议换亚克力立牌，不会被顾客撕、也不会被餐具压住。
  • 中心 Logo 用方形、主体居中的图，会被缩到码宽的 ~20% 再裁圆。
