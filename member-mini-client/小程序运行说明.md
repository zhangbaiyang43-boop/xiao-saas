# 小程序运行说明

## 推荐运行方式

当前项目按 uni-app CLI 项目维护，推荐用命令行构建，再用微信开发者工具打开产物。

```powershell
cd C:\Users\15936\Desktop\xiao\member-mini-client
npm run build:mp-weixin
```

构建成功后，在微信开发者工具中导入：

```text
C:\Users\15936\Desktop\xiao\member-mini-client\dist\build\mp-weixin
```

也可以导入源码根目录：

```text
C:\Users\15936\Desktop\xiao\member-mini-client
```

根目录的 `project.config.json` 已配置：

```json
{
  "miniprogramRoot": "dist/build/mp-weixin/"
}
```

所以微信开发者工具会自动从编译产物目录读取 `app.json`。

## HBuilderX 提示“node_modules缺少编译器模块”时

项目内编译器模块实际存在：

```text
node_modules\@dcloudio\uni-mp-weixin\dist\uni.compiler.js
```

如果 HBuilderX 仍提示缺少编译器模块，优先按下面顺序处理：

1. 关闭 HBuilderX 中当前项目。
2. 重新导入 `C:\Users\15936\Desktop\xiao\member-mini-client`。
3. 在 HBuilderX 内置终端执行：

```powershell
npm install --legacy-peer-deps
```

4. 仍失败时，使用命令行 `npm run build:mp-weixin` 构建，再用微信开发者工具导入 `dist\build\mp-weixin`。

这个项目后续以命令行构建作为稳定交付链路，HBuilderX 只作为编辑器使用。
