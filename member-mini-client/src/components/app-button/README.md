# AppButton

Foundation primitive for cross-page action buttons.

## API

- `variant`: `primary | secondary | ghost | danger`, default `primary`
- `size`: `sm | md | lg`, default `md`
- `block`: full-width layout
- `disabled`: disables interaction
- `loading`: disables interaction and shows stable loading affordance
- `click`: emitted only when not disabled and not loading

`AppButton` has no dish, cart, checkout, coupon, payment, or member logic.
